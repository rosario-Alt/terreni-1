## Ricerca terreni sui portali immobiliari

La pagina [ricerca.html](ricerca.html) è uno strumento separato dalla mappa: a partire dai criteri
inseriti (zona, prezzo, superficie, ecc.) genera i link di ricerca già compilati per
Immobiliare.it, Idealista.it, Subito.it, Casa.it e Bakeca.it. Funziona interamente nel browser,
senza chiamate a server esterni.
